# Architecture Diagram Review Checklist

- [ ] Title
- [ ] Diagram type
- [ ] Scope
- [ ] Intended audience
- [ ] Named elements
- [ ] Clear responsibilities
- [ ] Labelled relationships
- [ ] Correct relationship direction
- [ ] Technology choices where useful
- [ ] Acronyms explained
- [ ] Legend where needed
- [ ] Consistent abstraction level
- [ ] No unnecessary lower-level detail
