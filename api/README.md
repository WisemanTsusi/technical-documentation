# API Documentation

## Principles
- Explicit resource-oriented paths
- Standard HTTP semantics
- Input validation
- Machine-readable errors
- Authentication and authorization documentation
- Request/correlation IDs
- Consistent pagination/filtering
- Idempotency where required
- Compatibility and versioning strategy

## Contract-first workflow

```text
Requirement -> OpenAPI contract -> Review -> Implementation -> Contract tests
```

The OpenAPI Initiative maintains the authoritative specification and version history.
