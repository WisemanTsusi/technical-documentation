# System Context — Generic SaaS Platform

## Scope
A generic multi-tenant SaaS platform providing web and API capabilities.

## Actors
- Customer user
- Platform administrator
- Support/operator

## External systems
- Identity provider
- Payment provider
- Email provider
- Cloud infrastructure
- Observability platform

## Responsibilities
Authentication, tenant authorization, application capabilities, persistence, integrations and operational telemetry.

## Out of scope
Specific proprietary business-domain implementation.
